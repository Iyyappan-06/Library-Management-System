# 📚 Library Management System

A web-based Library Management System developed using React, Node.js, Express.js, and MySQL.

## ✨ Features

- Dashboard overview
- Add and manage books
- Manage library members
- Issue and return books
- MySQL database integration
- REST API integration

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML and CSS
- Node.js
- Express.js
- MySQL

## ⚙️ Project Setup

### Frontend

Open a terminal and run:

    cd frontend
    npm install
    npm run dev

### Backend

Open another terminal and run:

    cd backend
    npm install
    node server.js

## 🗄️ Database

- Database: MySQL
- Database name: library_management

Configure your database credentials in `backend/.env`.

**Security:** Never upload your `.env` file or database password to GitHub.
