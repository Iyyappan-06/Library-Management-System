# 📚 Library Management System

A full-stack Library Management System developed using React.js, Node.js, Express.js, and MySQL.

## 🚀 Features

- 📊 Dashboard with library statistics
- 📚 Book Management
- 👥 Member Management
- 🔄 Issue and Return Books
- 🔍 Search Books and Members
- ✏️ Edit Book and Member details
- 🗑️ Delete Books and Members
- ✅ Form validation
- ⚠️ Overdue book tracking
- 📱 Responsive user interface
- 🗄️ MySQL database integration
- 🔌 REST API integration

## 🛠️ Technologies Used

### Frontend

- React.js
- JavaScript
- HTML / JSX
- CSS
- Vite

### Backend

- Node.js
- Express.js
- REST API
- CORS

### Database

- MySQL
